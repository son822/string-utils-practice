# String Utils

![Python](https://img.shields.io/badge/python-3.x-blue)
![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)

A tiny collection of string helper functions, built as a practice project.

## Functions

- `reverse_words(sentence)` - reverse the order of words in a sentence.
- `is_palindrome(text)` - check whether text reads the same forwards and backwards.
- `count_vowels(text)` - count the number of vowels in text.
- `title_case(text)` - capitalize the first letter of every word.

## Running Tests

This project uses `pytest` for testing:

```bash
pytest test_string_utils.py
```
